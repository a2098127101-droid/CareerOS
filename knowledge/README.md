# CareerOS Knowledge Templates

默认产品模式为 `career_development`，核心知识层不绑定单一赛事、学校、专业或职业。

推荐按租户投喂：

- `policy_rule`：组织规则、项目要求、评价标准；
- `job_data`：岗位/职业公开知识（结构化岗位优先进入 Job Store）；
- `course`：课程与训练资源；
- `case`：案例，只能作为参考，不得当作当前用户事实；
- `template`：成果物模板；
- `internal`：组织内部资料。

`presets/career_competition/` 是可选业务模板，不属于默认产品身份。启用 `PRODUCT_PRESET=career_competition` 时才应使用对应赛事规则。
