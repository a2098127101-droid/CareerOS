# Release Notes · v1.0-alpha6

CareerOS v1.0-alpha6 moves the project closer to an operational Beta by adding certification and lifecycle tooling rather than adding more visual modules.

Highlights:

- live dependency certification report;
- SMTP/console email provider abstraction;
- invitation and password-reset email delivery;
- controlled delete/de-identification executor;
- backup/restore tooling;
- staging load-test harness;
- stricter production readiness diagnostics;
- continued SQLite/PostgreSQL repository contract parity.

The release remains **Alpha** because external production dependencies are not physically available in the current build environment and therefore are not claimed as verified.
