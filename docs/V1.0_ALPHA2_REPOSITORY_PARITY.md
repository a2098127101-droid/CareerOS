# CareerOS v1.0-alpha2 — Repository Parity

## Objective

Move v1.0-alpha1 from “repository foundation + first adapter” to a complete SQLAlchemy repository adapter surface while preserving SQLite local compatibility and refusing unsafe mixed-storage cutover.

## Implemented repository adapters

- Session
- Identity / Tenant
- Artifact / Versions
- Evidence
- Evidence Graph / Review Trace
- Workflow
- Feedback / AI Tasks
- Knowledge
- Structured Jobs
- Model Provider / Route / Usage
- Commercial / Analytics / Quota
- Storage Registry

`RepositoryContainer.build_postgresql()` now wires the complete adapter set only after:

1. code parity is complete;
2. PostgreSQL configuration has no blocking capability errors;
3. the target database contains the expected Alembic-provisioned schema.

It never silently mixes PostgreSQL and SQLite repositories.

## Important distinction

`code_parity_complete = true` means the adapter surface exists and passes deterministic contract tests.

It does **not** mean a live PostgreSQL deployment has been certified.

A final cutover requires a valid runtime certification generated by:

```bash
python scripts/certify_postgres.py --database-url "$DATABASE_URL"
```

The certification is bound to the database endpoint fingerprint and schema manifest SHA256.

## Generic core cleanup

Generic product mode no longer forces competition-track language in deterministic Agent fallbacks. Competition behavior remains an optional `career_competition` preset.

Default terminology:

- Participant
- Advisor
- Organization
- Group
- Career Development Report

Legacy aliases remain for compatibility.

## Security/data isolation hardening

Additional tenant filters were added to repository operations where tenant scope is known, including artifact series lookup, workflow lookup and evidence-trace expansion.

## Not completed in alpha2

- pgvector native retrieval
- Redis/distributed runtime
- background jobs
- Evidence semantic entailment
- signed private object download lifecycle
- real billing runtime
- real LLM provider E2E certification
