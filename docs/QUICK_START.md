# Quick Start

## Standalone demo

Open `CareerOS_H5_Showcase.html` directly. It contains generic demo data only and never requires API keys.

## Windows local application

Double-click `OPEN_CareerOS.cmd`.

## Development

```bash
python -m venv .venv
pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

Use `/admin` to configure product presets, providers, knowledge, structured jobs and commercial foundations.
