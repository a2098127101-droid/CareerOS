# CareerOS v1.0-alpha4 — Runtime Infrastructure Foundation

## Objective

Move CareerOS from a single-process commercial architecture MVP toward a distributed production runtime without breaking SQLite local development, existing APIs, Showcase Edition, Repository parity or generic product presets.

## Runtime topology

```text
Browser / Client
      │
      ▼
FastAPI API
      │
      ├── Repository Layer ── PostgreSQL (production) / SQLite (local)
      ├── Runtime State ───── Redis (production) / memory (local)
      ├── Background Jobs ─── Redis worker (production) / in-process (local)
      ├── Object Storage ──── S3-compatible (production) / local private files
      ├── LLM Gateway
      └── Hybrid RAG / Evidence Verification
```

## Fail-closed production rules

For `APP_ENV=production` + `DEMO_MODE=false`, configuration validation requires:

- authenticated production mode;
- strong application secret;
- secure cookies and explicit origins;
- PostgreSQL repository backend;
- Redis runtime state;
- Redis background job backend;
- S3-compatible object storage.

These configuration guards do not constitute live service certification. `/ready` and the admin readiness endpoint continue to surface runtime dependencies that are unavailable.
