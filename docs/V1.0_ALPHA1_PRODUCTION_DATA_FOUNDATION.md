# CareerOS v1.0-alpha1 · Production Data Foundation

## Scope

This release is the first implementation step toward the v1.0 Production Runtime. It does not claim full production readiness.

Implemented in this phase:

- Repository dependency container and repository interface contracts.
- SQLite remains the compatible local runtime.
- SQLAlchemy 2.x baseline metadata generated from the v0.9 schema.
- Alembic baseline migration for fresh databases.
- PostgreSQL-compilable baseline DDL.
- First SQLAlchemy repository parity adapter: session repository.
- SQLite snapshot export, PostgreSQL import dry-run, and migration verification tooling.
- Database readiness diagnostics and fail-closed production configuration boundaries.
- Canonical generic roles (`platform_admin`, `organization_admin`, `advisor`, `participant`) with legacy role aliases.
- Canonical `ParticipantProfile` compatibility model.
- Generic API aliases (`/participant`, `/advisor`, `/api/admin/groups`, `/api/advisor/...`).
- `enterprise_talent` Product Preset.

## Important boundary

`REPOSITORY_BACKEND=postgresql` is intentionally fail-closed in v1.0-alpha1 because full repository parity is not complete. The included PostgreSQL schema and migration tools are for provisioning and migration verification, not a claim that all runtime stores have been ported.

Remaining direct SQLite modules are tracked by:

```bash
python scripts/audit_database_access.py
```

No new application module should add direct SQLite access outside the explicitly listed legacy adapters.
