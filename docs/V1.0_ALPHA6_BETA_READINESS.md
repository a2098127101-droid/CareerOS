# CareerOS v1.0-alpha6 · Beta Readiness Foundation

## Scope

This release focuses on operational readiness rather than new UI surface area.

Implemented:

- runtime certification orchestration;
- outbound email provider abstraction (`console` / SMTP);
- invitation and password-reset delivery integration;
- controlled privacy deletion/de-identification;
- SQLite backup/restore tooling;
- PostgreSQL backup/restore wrappers;
- staging load-test harness;
- readiness diagnostics for email and runtime certification.

## Runtime certification

`python scripts/certify_runtime.py`

Checks are deliberately explicit:

- `PASS`: a live check succeeded;
- `FAIL`: a configured live check failed;
- `NOT_CONFIGURED`: dependency is absent;
- `NOT_VERIFIED`: code/config exists but a live proof was not executed.

The report is saved to `RUNTIME_CERTIFICATION_FILE` and surfaced through admin diagnostics.

## Privacy deletion

Deletion is controlled and policy-aware:

- preview first;
- explicit `confirm=true` required;
- executor disabled unless `PRIVACY_DELETE_EXECUTOR_ENABLED=true`;
- user-owned operational data is deleted;
- identity is de-identified and archived;
- audit/security/billing categories are retained pseudonymously by design.

This is not a claim of universal legal hard deletion. Retention policy must be tailored by jurisdiction and contract.
