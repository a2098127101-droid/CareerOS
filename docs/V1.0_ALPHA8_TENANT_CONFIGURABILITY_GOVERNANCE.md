# CareerOS v1.0-alpha8 · Tenant Configurability & Governance

## Scope

alpha8 continues the production-architecture track without claiming live external infrastructure certification. The release concentrates on four gaps that remained after alpha7:

1. built-in-only workflow/artifact templates;
2. insufficient governance for high-risk factual claims;
3. duplicate/replayed background jobs;
4. continued FastAPI composition-root growth.

## Implemented

### Tenant workflow registry

Tenant administrators can create workflow template drafts, edit drafts and activate a version. One active template is maintained per tenant/preset. Active templates are immutable; a changed workflow should be created as a new version. New workflow instances bind to the active template. Existing workflow instances retain their original step graph and template id.

Tables:

- `workflow_template_definitions`

APIs:

- `GET /api/admin/templates/workflows`
- `POST /api/admin/templates/workflows`
- `PUT /api/admin/templates/workflows/{template_id}`
- `POST /api/admin/templates/workflows/{template_id}/activate`

### Tenant artifact registry

Tenant administrators can create artifact template drafts with:

- canonical kind;
- label / aliases;
- renderer metadata;
- review rubric metadata;
- preset targeting;
- arbitrary JSON schema metadata.

Active tenant artifact templates resolve before built-in fallback templates.

Table:

- `artifact_template_definitions`

APIs:

- `GET /api/admin/templates/artifacts`
- `POST /api/admin/templates/artifacts`
- `PUT /api/admin/templates/artifacts/{template_id}`
- `POST /api/admin/templates/artifacts/{template_id}/activate`

### Evidence risk governance

Automated evidence verification now identifies high-risk factual claims including numeric statements and assertions involving certificates, awards, degrees, income, rankings/counts and similar facts. High-risk results carry:

- `risk_level=high`;
- `requires_human_review=true` until a human verification override is performed.

These fields are persisted on the current claim and in verification history. This does **not** claim a production-grade NLI/entailment model; it is a conservative governance layer on top of the existing deterministic + semantic-assisted verifier.

### Background-job reliability

The job contract now supports:

- tenant-scoped idempotency keys;
- worker lock metadata;
- heartbeat metadata;
- lease foundation for Redis workers;
- dead-letter metadata/list foundation;
- timeout metadata.

Equivalent async knowledge reindex requests now use an idempotency key so duplicate submissions return the same active job rather than duplicating expensive work.

### Router modularization

Template administration routes were moved to `app/routers/templates.py`. Existing paths are unchanged.

## Explicit non-claims

alpha8 does not claim live verification for:

- PostgreSQL/pgvector;
- Redis multi-instance failover;
- S3/R2/MinIO;
- external semantic embedding;
- external generation LLM;
- live observability exporters;
- PostgreSQL disaster recovery;
- 100/500/1000-concurrency production capacity;
- real billing or enterprise SSO.
