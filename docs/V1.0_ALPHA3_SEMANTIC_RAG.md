# CareerOS v1.0-alpha3 — Semantic RAG & Evidence Verification Foundation

## Scope

Alpha3 advances the v1.0 Production Runtime roadmap in two areas:

1. Hybrid retrieval from lexical/local-vector foundation toward a real semantic-provider + pgvector production path.
2. Evidence Graph from traceability toward conservative claim-support verification.

It does not claim that a live PostgreSQL server, live pgvector retrieval or a paid semantic embedding provider was available in the build environment.

## Delivered

### Retrieval

- Embedding provider gateway with local and remote-compatible modes.
- Batch embedding, retry/backoff and explicit fallback.
- Provider/model/dimension/warning metadata persisted with embeddings.
- PostgreSQL pgvector capability inspection.
- Exact cosine-distance pgvector search code path.
- Portable SQLite/vector-json fallback retained.
- Metadata, authority and effective-year filtering retained.
- RAG evaluation dataset/runtime and admin evaluation API.

### Evidence verification

- Persistent verification state on claims.
- SUPPORTED / PARTIALLY_SUPPORTED / CONTRADICTED / UNSUPPORTED / UNVERIFIED.
- Numeric consistency checks.
- Negation mismatch checks.
- Semantic similarity only when a true remote semantic provider succeeds.
- Tenant/session-scoped verification API.

### Database evolution

- SQLite migration 11.
- Alembic revision `0002_semantic_rag_pgvector`.
- RAG evaluation tables.
- pgvector extension/vector-column migration path.
- Schema manifest upgraded to alpha3 and preserved as a merged 33-table manifest.

## Non-goals / not yet ready

- No live PostgreSQL or pgvector E2E certification in this environment.
- No ANN/HNSW production index claimed.
- No LLM/NLI model used as final entailment judge yet.
- No Redis/background processing for large embedding jobs yet.
- No live semantic-provider credential was available for E2E certification.

## Recommended next phase

v1.0-alpha4 should focus on a real staging runtime:

1. PostgreSQL + pgvector live certification.
2. One real semantic embedding provider E2E.
3. Incremental reindex job execution against real pgvector.
4. Redis/background jobs.
5. Private file signed access.
6. Evidence NLI/LLM verifier as an optional second-stage judge.
