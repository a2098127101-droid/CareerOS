# CareerOS v1.0-alpha5 · Model Governance, Identity & Privacy Foundation

## Scope

Alpha5 extends the alpha4 runtime foundation without changing the dual-track product model.

### Showcase
- Single HTML.
- Generic anonymous Demo Data.
- No real API keys, payment, database or backend.
- Real hash-router navigation.

### Production
Alpha5 adds model governance, identity lifecycle, privacy/data-rights foundations and signed sandbox billing while preserving repositories, RAG, Evidence Graph, Workflow, Artifacts, runtime state, jobs and private storage.

## Implemented

### Model governance
- `llm_model_capabilities` registry.
- Capability-aware model recommendation and `auto` route foundation.
- Model-evaluation runs with success/JSON/content/latency/token/cost metrics.
- OpenAI-compatible native streaming foundation with buffered fallback.

### Identity lifecycle
- Tenant-scoped invitation creation/list/revoke/accept.
- Invitation tokens are random; only their SHA256 hash is stored.
- User disable/archive.
- Tenant role changes.
- Session revocation after sensitive lifecycle changes.

### Privacy
- Consent records with policy version and purpose.
- Authenticated user export.
- Data-subject request workflow.
- PII redaction/minimization before third-party model calls when enabled.

### Commercial foundation
- Signed mock BillingProvider only.
- HMAC webhook validation.
- Webhook idempotency keyed by provider + event key.
- No real payment provider is implemented or claimed.

## Explicit boundaries

- Live PostgreSQL/pgvector: NOT VERIFIED in this build environment.
- Live Redis: NOT VERIFIED.
- Live S3/R2/MinIO: NOT VERIFIED.
- Live semantic embedding: NOT VERIFIED.
- Real generation model E2E: NOT VERIFIED.
- Invitation email/SMTP delivery: NOT READY.
- Automatic destructive data deletion: NOT READY; only auditable requests exist.
- Enterprise DLP/NER: NOT READY; PII redaction is regex-based foundation.
- Stripe/WeChat Pay/Alipay: NOT READY.
- SSO: NOT READY.
