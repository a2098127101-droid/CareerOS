# StepIn / CareerOS

**从一件简单真实的工作开始，在做、改、再做和项目积累中形成真正会做的能力。**

[返回首页](README.md) · [开发路线图](ROADMAP.md) · [Foundation v1.9 PR #16](../../pull/16)

## StepIn 是什么

StepIn 面向零基础、零实习经验，甚至不知道真实工作每天具体在做什么的学生。

它不要求学生一开始就选专业、选岗位、学一堆课程或做职业测评，而是先给一件**真实、简单、马上能动手的小任务**。学生在不断做、修改、换场景再做和组合任务的过程中，逐渐形成真正能够独立完成、能够迁移、最后能够说清楚的实践能力。

核心路径：

**开始做 → 跟着做 → 自己做 → 根据反馈改 → 换场景再做 → 小任务组成项目 → 多任务叠加能力 → 把做过的事情讲出来。**

专业、课程和知识不是产品本身。它们只在学生当前任务真正需要时提供帮助。职业方向也不会要求学生一开始就决定，而是在完成多种真实任务以后逐渐出现。

## 先练会做事，再谈专业

Foundation 当前围绕 10 项跨专业公共实践能力组织入门任务：

1. 看懂任务；
2. 找出关键信息；
3. 整理信息；
4. 比较与判断；
5. 发现问题；
6. 说明理由；
7. 按要求清楚交付；
8. 根据反馈修改；
9. 换一个场景再做；
10. 把自己做过的事情讲清楚。

学生先完成一组足够简单的小任务。前期提示更多，后面逐渐减少，直到可以自己完成、根据反馈修改、换场景再做。之后几个小任务才会连成一个小项目，再逐渐进入不同专业的真实工作环境。

## 已形成的实践系统

StepIn 持续开发线已经形成：

- **今天只做一件事**：进入后直接处理当前任务；
- **Foundation Runtime**：零基础任务、提示逐步减少、基础成长记录；
- **Practice Runtime**：做 → 改 → 再做一次 → 成果；
- **不同工作的真实工作台**：表格、招聘、客户跟进、访谈整理、问题处理、资料研究、优先级判断；
- **对象旁提示**：需要时才在当前材料旁给一点帮助；
- **能力记录与作品**：保留真实操作、修改过程、反馈和版本；
- **换场景再做**：换材料、减少提示，检查是否真的会做；
- **教师成长视图**：不仅看答案，也看学生从“需要提示”到“能自己做”的变化；
- **Practice Studio**：受控创建、审核、试跑和发布新练习；
- **本机优先 / 离线**：核心练习以本机 FastAPI + SQLite 为基础，断互联网后仍可继续；
- **桌面发行基础**：Windows Portable、pywebview、WebView2 和 Inno Setup 构建链；
- **真实文件输出**：支持 DOCX、XLSX、PPTX、PDF 和 Markdown。

## 后续开发重点

当前不再优先增加更多岗位，而是先把底层闭环补齐：

1. **统一主线**：把 Foundation 正式接入 production `main`，结束两条代码线长期并行；
2. **Foundation 2.0**：把基础任务、提示撤离、Task Chain、小项目组合做成可配置能力；
3. **多任务能力叠加**：同一种能力必须在不同任务中反复出现，才能逐渐变成“我真的会做”；
4. **表达训练**：把做过的任务转成复盘、作品、简历和面试表达；
5. **Beginner Mode**：零基础阶段只显示当前一步，复杂工作台和高级功能后置；
6. **内容生产**：让老师和内容人员不用改源码，也能创建基础练习和任务链；
7. **Windows 真机发行**：安装、断网、备份、升级、恢复、本机 AI 和低配置电脑完整验证。

完整优先级见 [ROADMAP.md](ROADMAP.md)。

## 当前主分快速启动

Windows：

```text
OPEN_CareerOS.cmd
```

Python：

```bash
python -m venv .venv
pip install -r requirements.txt
uvicorn app.main:app --reload
```

本地演示账号配置见 `.env.example`。生产环境不要启用 Demo 用户自动生成。
